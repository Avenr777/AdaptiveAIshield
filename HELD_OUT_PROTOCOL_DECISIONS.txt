# AIShield: Pre-Registered Held-Out Evaluation Protocol
# Date: 2026-10-11
# Rule Zero: Decisions are documented here prior to running held-out evaluation.
# System code, weights, training data, and thresholds are FROZEN (see FROZEN.txt).

================================================================================
1. PRE-REGISTERED SYSTEM DECISIONS (NO CHANGES PERMITTED AFTER THIS)
================================================================================

1.1 Firewall Configuration (AIShield-Static):
- Ingress Normalization: 9-step normalization pipeline (NFKC, homoglyphs, whitespace collapse, hex/b64 decoding, leetspeak reversal).
- Layer Weights: Lexical = 0.35, Semantic = 0.45, Context = 0.20 (single-turn: active layer renormalization over Lexical and Semantic; Context = 0.0).
- Max-Fusion Trigger: S_l >= 85 raises final fast_score to max(S_l).
- Hard Veto: Lexical score >= 85 triggers BLOCK.
- BandConfig v2 (frozen on validation split val.jsonl):
    * Safe / Allow: score < 30.0
    * Warn / Flagged: 30.0 <= score <= 75.0
    * Block: score > 75.0
    * Decision mapping: ALLOW -> Benign (0), WARN/BLOCK -> Attack (1)
- Classifier Backend: models/aishield_classifier/classical_pipeline.joblib (SHA256 in FROZEN.txt)

1.2 Threshold Decision Rule:
- Fixed decision threshold: T = 30.0 (any prompt scoring >= 30.0 is classified as attack / positive).
- Zero threshold tuning on any held-out test data.

================================================================================
3. CONTAMINATION AUDIT PROTOCOL
================================================================================

- Any held-out sample with exact match against data/train.jsonl or data/val.jsonl (lowercased, whitespace-normalized) will be EXCLUDED.
- Word-level bigram Jaccard >= 0.80 or TF-IDF cosine >= 0.95 will be audited and flagged.
- Excluded count will be explicitly reported in contamination_report.json and the manuscript.

================================================================================
5. PRE-REGISTERED METRICS & STATISTICAL TESTS
================================================================================

- Primary Metrics:
    * AUROC (Area under ROC curve, threshold-free)
    * PR-AUC (Precision-Recall AUC, threshold-free)
    * TPR at fixed FPR of 1.0% (TPR@1%FPR)
    * Detection Rate (Recall), FPR, Precision, and F1 at fixed frozen threshold T=30.0
- Statistical Rigor:
    * Wilson 95% score intervals for proportions (Detection Rate, FPR)
    * Bootstrap 95% intervals (2,000 resamples, seed=42) for AUROC and F1
    * Paired McNemar's exact test comparing AIShield-Static against every baseline on matched prompts
- Latency Profiling:
    * Batch size = 1, single prompt
    * 50 warmup iterations discarded, 1,000 timed evaluations
    * Reporting p50, p95, p99 latency including full preprocessing and tokenization
